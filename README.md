
# 🎬 VYBORA
### Your Universe of Entertainment

VYBORA is a modern entertainment discovery platform that brings movies, web series, and music together in one immersive digital experience. It combines a cinematic interface, interactive features, and personalized discovery to make exploring entertainment enjoyable.

## ✨ Features

- 🎥 Discover trending movies and popular web series.
- 🎵 Explore music and curated entertainment collections.
- 🔍 Search and filter content by title, genre, and category.
- 🎭 Discover entertainment based on your mood.
- 🎲 Use Surprise Me to find something new.
- ❤️ Organize favourite entertainment in a personal library.
- 🧠 Participate in interactive entertainment quizzes.
- 🔐 Login, registration, and password recovery interfaces.
- 📱 Responsive design for desktop, tablet, and mobile.
- 🌌 Modern cinematic UI with gradients, animations, and stylish content cards.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Material UI (MUI)
- Redux Toolkit
- React Router
- CSS

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/VYBORA.git
```

Navigate to the project directory:

```bash
cd VYBORA
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
